关于项目

OpenHarmony Hi3861 环境监测预警系统 v2.0

🌡

OpenHarmony Hi3861 环境监测预警系统 v2.0

基于真实串口数据、Spring Boot、MySQL、DeepSeek Agent 的智能环境监测平台。

项目简介

基于 OpenHarmony Hi3861 的环境监测预警系统，硬件端采集温度、湿度、燃气数据，通过串口或 MQTT 实时传输到 Spring Boot 后端，存储到 MySQL 数据库，Web Dashboard 提供数据可视化、统计分析、温度预测和异常检测功能。

v2.0 核心变化

v2.0 将系统从传统 Dashboard 升级为以 温度计 Agent 为核心的智能环境分析平台。支持 DeepSeek 大模型流式输出、多轮对话上下文记忆、RAG 知识库检索。

数据真实性

页面默认读取 REAL_SERIAL 真实串口数据；如果切换到 MOCK，页面和 Agent 回答都会明确标记为模拟演示数据。

算法说明

使用滑动平均、线性回归、指数平滑进行短期温度预测，结合阈值检测、突变检测、连续升高检测进行异常诊断。适合趋势判断和短期预警，不是工业级精确温控模型。

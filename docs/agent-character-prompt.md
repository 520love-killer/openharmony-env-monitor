# Agent 形象设计提示词

## 中文提示词

为一个名叫“温度计”的 AI 环境监测助手生成一个 Web 吉祥物形象。它是一个拟人化温度计，身体像温度计，带有可爱的眼睛和微笑表情，整体风格科技感、简洁、适合大学生 OpenHarmony 环境监测系统。颜色以蓝色、白色和浅红色为主，表示温度变化。背景透明，适合作为网页 Agent 主页面头像。风格为现代 3D 卡通图标，清晰、干净、友好。

## 英文提示词

Create a web mascot character named "Thermometer", an AI environmental monitoring assistant. The character is an anthropomorphic thermometer with cute eyes and a friendly smile. It should look modern, clean, technological, and suitable for an OpenHarmony Hi3861 environment monitoring dashboard. Use blue, white, and soft red gradients to represent temperature changes. Transparent background, 3D cartoon icon style, clear and friendly.

## 图标版本

A cute anthropomorphic thermometer AI assistant icon, blue-white-red gradient, friendly face, technology style, transparent background, suitable for a web dashboard avatar.

## 当前实现

当前仓库没有提交 PNG 图片，而是提供了 SVG fallback：

- `src/main/resources/static/agent-thermometer.svg`：前端页面直接展示；
- `docs/images/agent-thermometer.svg`：文档和答辩素材使用。

SVG fallback 已包含温度计形状、小眼睛、微笑表情、蓝白红温度渐变和简洁科技风格。后续如生成 PNG，请保存为 `docs/images/agent-thermometer.png`。
